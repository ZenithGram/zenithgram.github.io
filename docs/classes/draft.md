# **MessageDraft**
Класс `MessageDraft` представляет собою объект, который используется для создания и отправки особых сообщений в режиме стриминга.

## Создание экземпляра `MessageDraft`
Для создания экземпляра класса используется `msgDraft` – метод из класса _ZG_. Этот метод является «синтаксическим сахаром»

### Параметры метода
| # | Название |     Тип      | Описание                     |
|:-:|:--------:|:------------:|------------------------------|
| 1 | **text** |   `string`   | Текст изначального сообщения |

### Возвращает
`MessageDraft` - экземпляр класса `MessageDraft`.

## Пример использования
```php
<?php
require_once __DIR__ . '/vendor/autoload.php';
use ZenithGram\ZenithGram\ZG;

$tg = ZG::create(BOT_TOKEN);

$draft = $tg->msgDraft("Привет, Мир!")->send();
sleep(3); // Никогда не используйте в реальном проекте, тут для наглядности
$draft->setText('Привет, Мир! Это сообщение дополнилось новым текстом')->send();
```

:::tip Особые условия
Такой тип сообщений возможно использовать только когда в вашем боте включен режим _ThreadedMode_
:::
